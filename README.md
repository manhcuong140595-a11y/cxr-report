# CXR Flight Report — bản web (iPhone & Android)

- **iPhone:** mở link bằng Safari → nút Chia sẻ → **Thêm vào MH chính**.
- **Android:** mở link bằng Chrome → menu ⋮ → **Thêm vào màn hình chính / Cài đặt ứng dụng**.

Sau lần mở đầu, app chạy không cần mạng. Dữ liệu chỉ lưu trên máy (không gửi đi đâu).
Thư mục này do `build-pwa.sh` tạo từ mã nguồn CXR_Mobile_Source (cùng giao diện với APK Android).
